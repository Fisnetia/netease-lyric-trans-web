# 网易云歌词翻译助手 Web 版

[English](README.md)

专为歌词翻译与校对打造的轻量级双语歌词对轴、多轨提取与在线编辑工作台。

## 核心功能

- **曲库检索与多轨透视**：搜索网易云音乐曲目，一键查看原文、译文、罗马音及双语合并歌词。
- **智能双语对轴**：快速将无时间轴译文精准对齐到带轴原文，自动处理插槽与演职员信息。
- **并排双语编辑器**：双栏逐行对照编辑，支持同步滚动、时间轴批量偏移与实时行数诊断。
- **格式与通道体检**：严格校验译文时间轴一致性、行数匹配度与格式规范。
- **日语辞书辅助**：集成在线日语词典查词与假名注音转写。
- **本地存储无登录**：无需登录任何账号，文稿保存在本地浏览器工作区。

## 快速使用

### 方式一：免安装便携版（推荐 Windows 用户）

从 [Releases](https://github.com/Fisnetia/netease-lyric-trans-web/releases) 下载 `netease-lyric-trans-portable-win64.zip`。  
解压后直接双击 `网易云翻译助手.exe` 即可使用，无需安装 Python 或手动配置依赖。

### 方式二：Python 源码运行

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 启动服务：

```bash
python gui.py
```

在浏览器中打开 `http://127.0.0.1:8765/` 即可。
